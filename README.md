# ベビーセーフ・ルーム

家庭内事故（起きて動いている赤ちゃんの事故）の予防知識を、遊びながら得られるトップビュー・シミュレーションゲーム。
仕様は [baby_safe_spec.md](baby_safe_spec.md)（v3.3）、モジュール間の契約は [docs/CONTRACT.md](docs/CONTRACT.md)。

- フェーズ1：Vanilla JS + Canvas 2D、音なし、単一 `index.html` で配布
- フェーズ2：Three.js + Web Audio API（同じゲームロジック `src/game/` を共有）

## 起動手順

```bash
npm install
npm run dev              # http://localhost:5173  （?mode=3d を付けるとフェーズ2の描画層で起動）
npm run build            # フェーズ1：dist/index.html 1 ファイル。ブラウザで直接開ける
npm run build:3d         # フェーズ2：dist-3d/（three.js を含む）。npx vite preview --outDir dist-3d で確認
```

対象環境は PC の Chrome 最新。マウス操作のみ。`?seed=123` を付けると乱数シードを固定できる。

## 遊び方（フェーズ1・2 共通）

キッチン（45 秒）→ 双子（45 秒）の 2 ステージ。長押しで「塞ぐ」操作はありません。すべて **ドラッグ＆ドロップ** で、
どこに落としたかで結果が決まります（レシピ → 容れ物 → 高い場所 → 床、の順に判定）。

| 操作 | 対象 | 効果 |
|---|---|---|
| ドラッグ | **軽いもの**（洗剤ボトル・電気ケトル・包丁、ボタン電池などの小物、おもちゃ、安全グッズ） | 床の好きな場所へ置き直す。軽い危険は動かしても危険なまま（届かない所に置けば安全） |
| ドラッグ → **高い場所**（カウンター・棚・テレビ台など、ヒント中に光る家具）へ | 軽いもの | 軽い危険は **対策済み** に（棚の上に小さく ✅ で残る）。小物・おもちゃ・グッズは片付けられて消える |
| ドラッグ → **容れ物**（フタ付きゴミ箱、キッチンのゴミ箱）へ | 小物・おもちゃ・安全グッズ | 捨てる（消える）。危険なものは捨てられない |
| ドラッグして重ねる | 安全グッズ → 対応する **重い危険**（コンセント・階段・テーブルの角・引き出し・ゴミ箱） | **即時に対策**（コンセントカバー → コンセント、ベビーゲート → 階段、ゴミ箱ロック → ゴミ箱 など。合わないものは無効） |
| ドラッグして重ねる | 軽い危険 → 収納先 | 収納して対策（包丁 → 引き出し） |
| ドラッグして重ねる | おもちゃ × おもちゃ | **合成**（積み木 × たいこ → 音の出る積み木、積み木 × ぬいぐるみ → くまの積み木タワー。満足度回復が大きく、赤ちゃんを強く引きつける） |
| ドラッグ | 赤ちゃん | 抱き上げて移す。嫌がってぐずり、危険なものに向かいやすくなる |
| 0.5 秒押す | おもちゃを持った赤ちゃん | 取り上げる。ぐずる |
| （動かせない） | **重いもの**（鍵の印・濃い影が付いた家具、容れ物） | 引っ張っても「動かない」。対応する安全グッズを重ねて対策する |

ドラッグ中は、落とせる場所（高い場所・容れ物・グッズの相手・合成相手・収納先）が脈打つ輪で光ります。
赤ちゃんが未対策の危険に触れると「ヒヤリ」。3 回で失敗。おもちゃで遊ぶと満足度が回復するが、同じおもちゃには飽きる（半透明＋「あきた」表示、リングは飽きの残り時間）。
赤ちゃんは速さにゆらぎがあり、ときどき立ち止まってきょろきょろします。

**ソファ**（双子ステージ）は登れる家具。赤ちゃんはソファに触れるとヒヤリにはならず **登って** ごきげんになりますが、登っている間に **転落** することがあります（ヒヤリ）。
安全グッズ **ジョイントマット** をソファに重ねるとソファの前に緑のマットが敷かれ、落ちてもマットの上で無事（ヒヤリにならない）。登っている赤ちゃんはドラッグで抱き下ろせます。
**おじさん**（無神経な訪問者）は **双子ステージ（ステージ 2）だけ** に現れ、途中で部屋を横切って **たばこ・小銭・薬のシート** を床に落として気にせず出て行きます。落とし物は誤飲の危険（小物）なので、ゴミ箱に捨てるか高い場所へ。おじさん自身には触れません。
**口に入れる猶予**：ボタン電池・洗剤・薬など小さな誤飲の危険に赤ちゃんが触れても、すぐにはヒヤリになりません。赤ちゃんは物を **口元にくわえ**（頭上に赤いリングが残り時間で縮む）、数秒後に飲み込む（ヒヤリ）か手放す（「ほっ」）かが決まります。くわえている間に **0.5 秒押して取り上げる** か抱き上げれば防げます。
**高い場所は 2 個まで**：カウンター・棚・テレビ台にはそれぞれ 2 個までしか置けません（ラベル横の `n/2`）。満杯だとヒントが赤くなり、落としても「もう置けない」と床に戻ります。何を上げるかを選ぶことになります。
**ダミー**（クッション・雑誌・スリッパ、ベージュの角丸）は危険でもおもちゃでもない軽い物。ドラッグはできますが赤ちゃんは無視します。高い場所に置くと容量を消費し、猫が運ぶこともあります。
**危険なおもちゃ**（ジグソーパズル、右上にオレンジの「！」）は普通に遊べますが、遊び終えると小さなピースを口に入れることがあります。取り上げて防ぐか、届かない所へ。
**猫**（双子ステージの終盤）は床の軽い物をくわえて **赤ちゃんのそばに置いていきます**（危険な小物が優先）。猫には触れないので、置かれた物をすぐ片付けてください。
画面右の **できごとログ** に「ボタン電池を口に入れそうになった！（誤飲）」「洗剤ボトルを棚の上へ移した。届かない」のように原因と結果が一文で流れる。結果画面には失敗の原因の内訳が出る。
ステージ・重さ・高い場所・レシピの定義は `src/game/stages.js`（`STAGES` / `ALL_RECIPES` / `MERGED_TOYS`）、ログ文言は `src/game/log.js`。

```

src/render/    描画層  canvas2d/（フェーズ1） three/（フェーズ2）

src/ui.js      HUD・各画面（HTML を重ねる）   src/input.js  マウス→操作イベント   src/main.js  ループ・DI
sim/           ヘッドレス自動テストプレイ（§13）  tests/  単体テスト・Playwright
assets/models  glb 置き場   assets/audio  効果音・BGM 置き場
```

## テスト

```bash
npm run test:game        # ゲームロジックの単体テスト（node --test）
npm run check:pure       # src/game/ が DOM / Canvas / Math.random を参照していないことを grep で確認
npm run test:browser     # Playwright：フェーズ1を実際にクリックして遷移・ドラッグ＆ドロップ（対策・収納・捨てる・高い場所）を確認（tests/screenshots/ に保存）
npm run test:browser3d   # 同上、フェーズ2（WebGL はソフトウェア描画）
```

## シミュレーション（`npm run sim`）

`src/game/` を Node 上で `dt = 1/60` で回し、ボット 5 種（`noop` / `optimal` / `intervene_only` / `random` / `human_like`）で難易度を数値化する。
人間に遊ばせる前に、ここで §13.3 の指標を目標範囲に入れる。

```bash
npm run sim -- --stage 1 --bot optimal --n 1000        # 1 セル。要約表を表示し sim/out/1-optimal.json に保存
npm run sim -- --stage all --bot all --n 300 --workers 4
npm run sim -- --stage 2 --bot human_like --n 200 --tuning '{"BABY_SPEED":60}'
npm run sim:assert                                     # §13.3 の全指標を判定（n=300/セル）。1 つでも外れると exit 1
npm run sim:assert -- --fast                           # n=60 の簡易版
npm run sim:tune -- --workers 6                        # §13.4：5 変数 × 3 水準 = 243 条件のスイープ。通る条件を列挙
```

詳細は [sim/README.md](sim/README.md)。乱数はシード固定なので、同じ `--seed` なら同じ結果になる。

## 素材（フェーズ2・人間側の作業）

ファイルが無くてもプレースホルダー（箱形状・合成音）で全ステージ遊べる。置くとそのファイルだけ差し替わる。

| 置き場所 | 内容 |
|---|---|
| `assets/models/<model>.glb` | 家具・オブジェクト。`model` 名は `src/game/stages.js` の各オブジェクトの `model`（例 `outlet`）、対策後は `fixedModel`（例 `outlet_fixed`）、walls は `sofa` `tv_stand` `shelf` `counter` `island` `fridge` |
| `assets/models/baby.glb` | 赤ちゃん。アニメーションクリップ名 `crawl` `idle` `stun` `play`（`fuss` `held` は省略可） |
| `assets/audio/<name>.mp3`（または .ogg） | `click` `fix_done` `play_done` `hiyari` `combo_warn` `pickup` `fuss` `respawn` `clear` `fail` `bgm_main` `bgm_bored` |

生成の指示は仕様書 §9.3（「low-poly, flat-shaded, toy-like, pastel colors」、1 モデル 5,000 ポリゴン以下、効果音は「toy-like, soft, not scary」）。
